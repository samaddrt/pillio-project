◆ calculateNextIntake()

TimePoint pillio::calculateNextIntake ( const Pill & pill,
const std::vector< Schedule > & history,
const TimePoint & now )

Вычисляет время следующего приёма лекарства.

Алгоритм учитывает:

  • интервал между приёмами (pill.interval_hours);
  • время начала (pill.start_hour, pill.start_minute);
  • историю приёмов (history) — пропускает уже принятые слоты;
  • «сегодняшний» диапазон (00:00 .. 23:59) относительно now.
Parameters
pillописание лекарства
historyвектор записей расписания (уже существующих)
nowтекущий момент времени
Returns
время следующего запланированного приёма
Exceptions
ValidationErrorесли pill не проходит валидацию.
