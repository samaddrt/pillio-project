# Pillio для Android (Google Play)

Гибридная версия Pillio:

* **Лекарства, расписание, статистика** — полностью офлайн на устройстве
  (localStorage; логика перенесена из C++-бэкенда).
* **Напоминания** — нативные уведомления Android, время подстраивается под
  связь с едой (до еды → за 30 мин раньше, после еды → на 20 мин позже).
* **Семья** — через сервер Pillio (адрес в константе `SERVER` в
  `www/index.html`); мой прогресс зеркалируется на сервер фоновой
  синхронизацией, близкие видят его так же, как в Telegram-версии.
* **AI-помощник** — кнопка ✨ на главной; вопрос уходит на сервер
  (`/api/ai/ask`), который проксирует его в Google Gemini. Ключ хранится
  только на сервере: переменная окружения `GEMINI_API_KEY` в Replit
  (бесплатный ключ: https://aistudio.google.com → Get API key).
  Без ключа помощник вежливо сообщает, что не настроен.

Эта папка не затрагивает курсовой C++-проект — он живёт в корне репозитория.

## Что нужно установить (один раз)

1. **Node.js** ≥ 18 — уже есть.
2. **Android Studio** (бесплатно): https://developer.android.com/studio
   При первом запуске она сама поставит Android SDK и JDK.

## Сборка

```bash
cd app
npm install                 # ставит Capacitor
npx cap add android         # один раз: создаёт папку android/ (нативный проект)
npx cap sync android        # копирует www/ внутрь нативного проекта
npx cap open android        # открывает проект в Android Studio
```

Дальше в Android Studio:

* **Запустить на телефоне/эмуляторе:** кнопка ▶ Run.
* **Собрать релиз для Play:** `Build → Generate Signed Bundle / APK → Android App Bundle`.
  * При первом разе создай keystore (`Create new…`) — **сохрани файл и пароли**,
    без них нельзя выпускать обновления.
  * На выходе получится `app-release.aab`.

После любых правок `www/index.html` повторяй `npx cap sync android`.

## Публикация в Google Play (делается вручную)

1. Аккаунт разработчика: https://play.google.com/console — разовый взнос **$25**,
   нужна верификация личности.
2. «Создать приложение» → загрузить `app-release.aab` в **Internal testing**
   (сначала), затем в Production.
3. Заполнить обязательное:
   * **Политика конфиденциальности** — ссылка на опубликованный текст
     (шаблон: `privacy-policy.md`; можно выложить на GitHub Pages).
   * **Data safety**: данные не собираются и не передаются — всё на устройстве.
   * Скриншоты (телефон, минимум 2), иконка 512×512, описание.
   * Анкета возрастного рейтинга. Категория: «Здоровье и фитнес» или «Медицина».
4. У новых аккаунтов Google требует **закрытое тестирование: ≥12 тестировщиков
   в течение 14 дней**, прежде чем пустить в Production — закладывай время.

## Уведомления

* Разрешение запрашивается при первом входе (Android 13+ — системный диалог).
* Планируются слоты на 7 дней вперёд (до 60 уведомлений — лимит ОС обходим
  перепланированием при каждом открытии приложения / изменении лекарств).
* В обычном браузере плагина нет — приложение работает, просто без уведомлений.

## Иконка уведомлений

`capacitor.config.json` ссылается на `ic_stat_pill`. После `cap add android`
добавь монохромную иконку в `android/app/src/main/res/drawable*/ic_stat_pill.png`
(Android Studio: правый клик по `res` → New → Image Asset → Notification Icons).
Пока её нет — Capacitor использует иконку приложения по умолчанию.
